# Gestión de Caja 💰

Software de escritorio desarrollado por **Bytespc.es** para el control de caja y arqueo diario. 

Ideal para pequeños negocios (churrerías, panaderías, bares) que desean cruzar los datos de su TPV (ventas en efectivo y tarjeta) con el dinero físico real del cajón para detectar descuadres.

## 🚀 Descarga e Instalación
Para instalar el programa, ve a la sección de **[Releases](../../releases)** en la barra derecha y descarga el archivo `.exe`. 

## 📚 Documentación
El manual de usuario completo, junto con los recursos visuales, se encuentra en la carpeta **[`docs`](docs/)** de este repositorio.

## ⚙️ Características principales
*   Cálculo automático de descuadres (Verde = perfecto, Rojo = descuadre).
*   Gestión de turnos (Mañana, Tarde o Jornada Completa).
*   Registro de gastos pagados en efectivo con nombre del proveedor.
*   Descarga de informes en PDF y copias de seguridad.
*   Interfaz local segura, los datos no salen de tu ordenador.
