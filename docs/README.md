
# Gestión de Caja - Bytespc.es

Bienvenido a la documentación oficial del software **Gestión de Caja**.

Este directorio contiene los archivos necesarios para que el usuario final pueda entender el funcionamiento del programa.

## Contenido de esta carpeta

*   **manual.html**: El código fuente del manual de usuario (se puede visualizar en cualquier navegador).
*   **manual.pdf**: El manual de usuario listo para descargar o imprimir.
*   **logo.png**: El logotipo de la empresa para el manual.

## Sobre el software

Gestión de Caja es una herramienta de escritorio diseñada para el arqueo y cierre de caja diario. Permite cruzar los datos del TPV (ventas en efectivo y tarjeta) con el dinero físico real del cajón, detectando descuadres de forma automática.
